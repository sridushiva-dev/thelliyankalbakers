# Thelliyankal · Grand Reserve UI

Apply on top of TypeUI **cafe** (active) + **typeui-fundamentals**.

## Intent

Premium plum-cake gifting: heritage (since 1980), whiskey-style packaging, festive Christmas campaigns. Feel like a luxury D2C brand, not a generic Shopify template.

## Tokens (override premium defaults)

| Role | Value | Usage |
|------|--------|--------|
| Background (60%) | `#f9f7f5` (cafe surface) | Page canvas |
| Surface card | `#ffffff` | Cards, tables |
| Brand (30%) | `#5d4432` / `#3e2b1e` (cafe primary) | Headers, coffee sections |
| Secondary bands | `#e9e3dd` | Warm section backgrounds |
| Accent (10%) | `#d97706` (cafe warning) | CTAs, kickers, focus rings |
| Accent soft | `#fcd34d` | Highlights on dark (stats, prices) |
| Text primary | `#3e2b1e` | Body on light |
| Text muted | `#6b5a4d` | Secondary copy |
| Border | `#ddd5cc` | Cards, dividers |

## Typography

- **Display:** Fraunces — editorial headlines (heritage / gifting).
- **UI:** Poppins — 16px base, 1.5–1.65 line-height (TypeUI cafe).
- Scale: 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 (1.25 ratio).

## Layout

- Max content width: `1120px`.
- Section padding: 64–96px vertical, 24px horizontal.
- Feature rows: horizontal flex (icon + title + body), never multi-column text inside a single card cell.

## Components

- **Primary button:** filled accent, 44px min height, pill radius, focus-visible ring.
- **Pricing / proposals:** sticky summary card + line-item table; market comparison row highlighted.
- **Hero:** split layout — story left, proof/metrics right.

## Copy tone

Confident, warm, specific — promise the *best online home* for the product; back claims with scope and market comparison.
